# Example document

`sample-campus.pdf` is a fictional, one-page handbook for the runnable demonstration. It is not a BNBU policy document. Add PDFs you are authorized to process here and run `python scripts/index_documents.py` to index them in your configured Neo4j database.

Try: “When does the sample campus library close on weekdays?” The document says 22:00, with page 1 as its source.
